# KAI Draft Site Refresh — Fashion

Status: DRAFT ONLY — do not merge without owner approval.

## Evidence
- Live homepage currently leads with “Women’s activewear for movement, comfort and everyday UAE routines.”
- GSC (last 28 settled days through 2026-09-27): 40 impressions, 3 clicks, CTR 7.5%, avg position 9.5 for the domain property.
- Homepage has appeared around position 4 in the recent page-level window.

## Copy audit
1. Hero and the next two sections repeat “movement / comfort / everyday” too often.
2. “Suitable for UAE active lifestyle” is generic and weak as product proof.
3. Amazon checkout reassurance is useful but repeated enough to dilute product appeal.
4. Product copy needs stronger differentiation between leggings, classic bra and criss-cross bra.
5. The “Campaign look” section is visually promising but its copy does not add a strong reason to explore products.

## Draft direction
- Hero: shorter, more product-led, with one strong UAE-specific proposition.
- Reduce Amazon reassurance to one concise trust strip.
- Replace generic bullets with fit/use-case differentiation.
- Add a compact visual “Shop by routine” section: Gym / Walking / Yoga / Everyday.
- Preserve current multilingual structure.

## Visual draft direction
- Premium editorial activewear look; restrained motion only.
- Hero: subtle layered depth, no autoplay heavy video.
- Micro-motion: product-card lift, CTA feedback, gentle image reveal.
- Optional media draft: 6–8 sec muted WebM loop or lightweight animated WebP, only if Lighthouse impact is acceptable.
- Respect prefers-reduced-motion.
