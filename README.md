# KAVOMAZ Static Website

This is a static replacement for the old WordPress website.

## Before uploading
1. Open `index.html`.
2. Replace these Amazon placeholder links with the real Amazon.ae product links:
   - `https://www.amazon.ae/dp/PASTE_YOGA_BRA_ASIN_HERE`
   - `https://www.amazon.ae/dp/PASTE_LEGGINGS_ASIN_HERE`
   - `https://www.amazon.ae/dp/PASTE_SET_ASIN_HERE`
3. Replace placeholder SVG images in `/images` with real product photos if you have them.
4. Keep image file names the same, or update the file names inside `index.html`.

## Upload to GitHub
Upload all files to your GitHub repository root:
- index.html
- style.css
- script.js
- CNAME
- .nojekyll
- robots.txt
- sitemap.xml
- 404.html
- images folder

## Custom domain
The CNAME file is set to:
kavomaz.com

If your domain is different, edit the CNAME file.
