## How to upload
Upload these files to the root of your GitHub repository:
- index.html
- style.css
- script.js
- CNAME
- .nojekyll
- robots.txt
- sitemap.xml
- 404.html
- images folder

## Add your own real product photos later
Put real photos in /images and then replace the placeholder boxes in index.html with img tags.

Example:
<img src="images/leggings-black.jpg" alt="KAVOMAZ high-waist leggings in black">
